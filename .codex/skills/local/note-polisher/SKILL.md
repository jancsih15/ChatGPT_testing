# Note Polisher

## Workflow

1. Extract key points without changing meaning.
2. Produce a concise summary in 3-5 bullets.
3. List action items with owner, task, and due date when present.
4. List open questions when information is missing.

## Rules

- Preserve factual meaning; do not invent details.
- If dates are relative or ambiguous, ask for exact dates.
- Keep wording direct and concise.
